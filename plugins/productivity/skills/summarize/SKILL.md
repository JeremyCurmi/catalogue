# Summarize

Take the previous message and say the same thing in plain language.

## What to summarize

The most recent substantial message before this one — usually your own last reply. If the user pasted text or gave a file, summarize that instead. If it is genuinely unclear which, ask in one line.

## Rules

- **No jargon.** Replace every technical term with what it actually means. If a term has no plain equivalent, spell it out once in ordinary words.
- **Expand or drop acronyms.** Never leave a reader guessing what the letters stand for.
- **Short sentences.** One idea each.
- **Keep the substance** — names, numbers, decisions, warnings, next steps. Losing those is a failed summary.
- **Add nothing.** No new claims, no advice that was not in the original, no interpretation of what it "really" means.
- **Shorter than the original.** Considerably. If it does not fit in a few lines, use short bullets.
- Uncertainty in the original stays uncertain in the summary. Do not sand off a hedge into a fact.

## Output

Plain text. No headings, no preamble, no "here is a summary of". Just the summary.
